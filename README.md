# SmartChef

## 1. Жоба туралы

**SmartChef** — қолда бар азық-түлік өнімдеріне негізделіп, рецепт ұсынатын веб-қосымша. Жоба Django көмегімен жасалған. Интерфейс қазақ және орыс тілдерін қолдайды.

## 2. Жобаның мақсаты

Пайдаланушыға үйде бар өнімдерден тағам дайындауға көмектесу, рецептті көру және оны қадам бойынша орындау мүмкіндігін ұсыну.

## 3. Т1–Т8 жұмыстарының нәтижелері

### T1. Жобаның негізін дайындау
Django жобасының құрылымы дайындалды. Қосымшаның негізгі конфигурациясы және іске қосылуы тексерілді.

### T2. Рецепт генерациясы
Пайдаланушы өнімдерді енгізіп, тағам дайындауға арналған рецепт сұрай алады. Рецепт генерациясы Gemini API арқылы орындалады.

### T3. Тіл және параметрлер
Қазақ және орыс тілдерін таңдау, дайындалу уақытын көрсету және вегетариандық параметрін қолдану қарастырылған.

### T4. Рецепт нәтижесін көрсету
Генерацияланған рецепт интерфейсте көрсетіледі. Қате жағдайларын өңдеу мүмкіндігі қарастырылған.

### T5. Өнімдер каталогы
Өнімдерді санаттар бойынша таңдау, іздеу және сүзу интерфейсі жасалды. Қолмен қосымша өнім енгізуге болады.

### T6. Сақталған рецепттер
Рецепттерді сақтау және сақталған рецепттер бетінде көрсету функционалы қарастырылған.

### T7. Дайындау режимі
Рецептті қадам бойынша орындауға арналған жеке режим қосылды. Пайдаланушы ағымдағы қадамды қарап, келесі қадамға өте алады.

### T8. Тексеру және Git
Жоба күйі тексерілді, Git арқылы коммиттер жасалды және код GitHub репозиторийіне жіберілді. Негізгі жұмыс тармағы — `main`.

## 4. Қолданылған технологиялар

- Python
- Django
- HTML, CSS, JavaScript
- SQLite
- Gemini API
- Git және GitHub

## 5. Жобаны іске қосу

1. Виртуалды ортаны іске қосыңыз.
2. Тәуелділіктер орнатылғанына көз жеткізіңіз.
3. `.env` файлына Gemini API кілтін және қажетті конфигурацияны енгізіңіз.
4. Терминалда орындаңыз:

```bash
python manage.py check
python manage.py migrate
python manage.py runserver
```

5. Браузерде `http://127.0.0.1:8000/` мекенжайын ашыңыз.

## 6. Қауіпсіздік

API кілттері мен құпия конфигурация `.env` файлында сақталуы керек. `.env` және SQLite дерекқоры GitHub репозиторийіне жүктелмеуі тиіс.
