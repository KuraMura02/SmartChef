# SmartChef

## 1. Жоба туралы

**SmartChef** — қолда бар азық-түлік өнімдеріне негізделіп, рецепт ұсынатын веб-қосымша. Жоба Django көмегімен жасалған. Интерфейс қазақ және орыс тілдерін қолдайды.

## 2. Жобаның мақсаты

Пайдаланушыға үйде бар өнімдерден тағам дайындауға көмектесу, рецептті көру және оны қадам бойынша орындау мүмкіндігін ұсыну.

## 3. Т1–Т8 жұмыстарының нәтижелері

### T1. Жобаның негізін дайындау
Django жобасының құрылымы дайындалды. Қосымшаның негізгі конфигурациясы және іске қосылуы тексерілді.

### T2. Рецепт генерациясы
Пайдаланушы өнімдерді енгізіп, тағам дайындауға арналған рецепт сұрай алады. Рецепт генерациясы Gemini API арқылы орындалады.

### T3. Тіл және параметрлер
Қазақ және орыс тілдерін таңдау, дайындалу уақытын көрсету және вегетариандық параметрін қолдану қарастырылған.

### T4. Рецепт нәтижесін көрсету
Генерацияланған рецепт интерфейсте көрсетіледі. Қате жағдайларын өңдеу мүмкіндігі қарастырылған.

### T5. Өнімдер каталогы
Өнімдерді санаттар бойынша таңдау, іздеу және сүзу интерфейсі жасалды. Қолмен қосымша өнім енгізуге болады.

### T6. Сақталған рецепттер
Рецепттерді сақтау және сақталған рецепттер бетінде көрсету функционалы қарастырылған.

### T7. Дайындау режимі
Рецептті қадам бойынша орындауға арналған жеке режим қосылды. Пайдаланушы ағымдағы қадамды қарап, келесі қадамға өте алады.

### T8. Тексеру және Git
Жоба күйі тексерілді, Git арқылы коммиттер жасалды және код GitHub репозиторийіне жіберілді. Негізгі жұмыс тармағы — `main`.

## 5. Жобаны іске қосу

SmartChef жобасын іске қосу үшін Python виртуалды ортасын дайындап, қажетті кітапханаларды орнатып, қоршаған орта айнымалыларын баптап, дерекқор миграцияларын орындау қажет. Төмендегі командалар Windows және PowerShell ортасына арналған.

### 5.1. Жоба бумасына өту

Терминалды ашып, `manage.py` файлы орналасқан жоба бумасына өтіңіз.

Мысалы:

```powershell
cd "C:\Users\Student\Documents\smartchef\smartchef"
```

**Ескерту:** жолды өз компьютеріңіздегі жоба орналасқан мекенжайға сәйкес өзгертіңіз.

### 5.2. Виртуалды ортаны тексеру және іске қосу

Виртуалды орта Python кітапханаларын басқа жобалардан бөлек сақтауға мүмкіндік береді.

Егер `.venv` виртуалды ортасы жоба бумасында бұрыннан бар болса, оны іске қосыңыз:

```powershell
.\.venv\Scripts\Activate.ps1
```

Егер виртуалды орта әлі құрылмаса, оны жасаңыз:

```powershell
py -m venv .venv
```

Содан кейін ортаны іске қосыңыз:

```powershell
.\.venv\Scripts\Activate.ps1
```

Егер PowerShell сценарийлерді іске қосуға тыйым салса, виртуалды ортаны белсендірмей-ақ командаларды `.venv\Scripts\python.exe` арқылы орындауға болады.

Python нұсқасын тексеріңіз:

```powershell
python --version
python -m pip --version
```

### 5.3. Тәуелділіктерді орнату

Жобаның негізгі бумасында орналасқан `requirements.txt` файлы арқылы қажетті кітапханаларды орнатыңыз:

```powershell
python -m pip install -r requirements.txt
```

Django нұсқасын тексеріңіз:

```powershell
python -m django --version
```

### 5.4. Қоршаған орта айнымалыларын баптау

`manage.py` файлы орналасқан буманың ішінде `.env` файлы болуы керек. Онда Gemini API кілті және жобаға қажетті басқа конфигурациялар сақталады.

Мысалы:

```env
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.8-flash
```

`your_gemini_api_key` орнына өзіңіздің жарамды API кілтіңізді енгізіңіз. Модель атауы жобада қолдау көрсетілетін модельге сәйкес болуы керек.

**Қауіпсіздік ережесі:** `.env` файлын GitHub репозиторийіне жүктемеңіз және API кілтін бастапқы кодта ашық сақтамаңыз.

### 5.5. Жоба конфигурациясын тексеру

Django конфигурациясындағы қателерді тексеріңіз:

```powershell
python manage.py check
```

Егер тексеру сәтті өтсе, мынадай хабарлама көрсетіледі:

```text
System check identified no issues (0 silenced).
```

### 5.6. Дерекқор миграцияларын орындау

Жоба коды жаңартылғаннан кейін дерекқордың құрылымын жаңарту қажет. Бұл қадам әсіресе жобаны басқа компьютерде алғаш іске қосқанда маңызды.

Алдымен қолданыстағы миграциялардың күйін тексеріңіз:

```powershell
python manage.py showmigrations recipes
```

Егер модельдер өзгертіліп, оларға арналған миграция файлдары әлі жасалмаса, жаңа миграцияларды құрыңыз:

```powershell
python manage.py makemigrations
```

Содан кейін барлық қажетті миграцияларды қолданыңыз:

```powershell
python manage.py migrate
```

Бұл команда Django қолданбаларының дерекқор кестелерін құрады немесе олардың құрылымын жаңартады. Мысалы, рецепт нұсқаларының тарихын сақтауға арналған `RecipeVersion` моделі қолданылса, оған қажетті кесте де тиісті миграция арқылы құрылады.

**Маңызды:** `makemigrations` командасы жаңа миграция файлын қажет болған жағдайда ғана жасайды. Егер миграция файлы репозиторийде бар болса, оны қайта жасау міндетті емес. Дерекқорды жаңарту үшін `migrate` командасын орындау жеткілікті. `db.sqlite3` файлын жоймаңыз, себебі онда сақталған рецепттер болуы мүмкін.

### 5.7. Серверді іске қосу

Жергілікті әзірлеу серверін іске қосыңыз:

```powershell
python manage.py runserver
```

Браузерде келесі мекенжайды ашыңыз:

```text
http://127.0.0.1:8000/
```

Серверді тоқтату үшін терминалда `Ctrl + C` пернелерін басыңыз.

### 5.8. Негізгі мүмкіндіктерді тексеру

Жоба іске қосылғаннан кейін келесі әрекеттерді тексеріңіз:

1. Басты беттің ашылуы.
2. Қазақ және орыс тілдерін ауыстыру.
3. Өнімдер бойынша рецепт генерациялау.
4. Рецептті сақтау және сақталған рецепттер тізімін ашу.
5. Рецептті өңдеу, соңғы нұсқасын сақтау және алдыңғы нұсқаға қайтару мүмкіндіктері, егер олар жоба нұсқасында іске асырылған болса.
6. Дайындау режимінде қадамдарды растау және келесі қадамға өту.

Егер қате пайда болса, терминалдағы хабарламаны тексеріп, оның себебін анықтаңыз. Дерекқор кестесінің жоқтығы туралы қате шықса, алдымен миграциялардың бар-жоғын және олардың қолданылғанын тексеріңіз.
