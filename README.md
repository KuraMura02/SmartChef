# SmartChef

## 1. Жоба туралы

**SmartChef** — қолда бар азық-түлік өнімдеріне негізделіп, рецепт ұсынатын веб-қосымша. Жоба Django көмегімен жасалған. Интерфейс қазақ және орыс тілдерін қолдайды.

## 2. Жобаның мақсаты

Пайдаланушыға үйде бар өнімдерден тағам дайындауға көмектесу, рецептті көру және оны қадам бойынша орындау мүмкіндігін ұсыну.

## 3. Т1–Т8 жұмыстарының нәтижелері

### T1. Жобаның негізін дайындау
Django жобасының құрылымы дайындалды. Қосымшаның негізгі конфигурациясы және іске қосылуы тексерілді.

### T2. Рецепт генерациясы
Пайдаланушы өнімдерді енгізіп, тағам дайындауға арналған рецепт сұрай алады. Рецепт генерациясы Gemini API арқылы орындалады.

### T3. Тіл және параметрлер
Қазақ және орыс тілдерін таңдау, дайындалу уақытын көрсету және вегетариандық параметрін қолдану қарастырылған.

### T4. Рецепт нәтижесін көрсету
Генерацияланған рецепт интерфейсте көрсетіледі. Қате жағдайларын өңдеу мүмкіндігі қарастырылған.

### T5. Өнімдер каталогы
Өнімдерді санаттар бойынша таңдау, іздеу және сүзу интерфейсі жасалды. Қолмен қосымша өнім енгізуге болады.

### T6. Сақталған рецепттер
Рецепттерді сақтау және сақталған рецепттер бетінде көрсету функционалы қарастырылған.

### T7. Дайындау режимі
Рецептті қадам бойынша орындауға арналған жеке режим қосылды. Пайдаланушы ағымдағы қадамды қарап, келесі қадамға өте алады.

### T8. Тексеру және Git
Жоба күйі тексерілді, Git арқылы коммиттер жасалды және код GitHub репозиторийіне жіберілді. Негізгі жұмыс тармағы — `main`.

## 5. Жобаны іске қосу

SmartChef жобасын іске қосу үшін Python виртуалды ортасын дайындап, қажетті тәуелділіктерді орнатып, дерекқорды баптау қажет. Төмендегі командалар Windows және PowerShell ортасына арналған.

### 5.1. Жоба бумасына өту

Алдымен терминалды ашып, `manage.py` файлы орналасқан жоба бумасына өтіңіз.

```powershell
cd "C:\Users\..."
```

*Ескерту: жолды өз компьютеріңіздегі жоба орналасқан мекенжайға сәйкес өзгертіңіз.*

### 5.2. Виртуалды ортаны тексеру және іске қосу

Виртуалды орта жобаның тәуелділіктерін жүйедегі басқа Python жобаларынан бөлек сақтауға мүмкіндік береді.

Егер виртуалды орта бұрыннан жасалған болса, оны іске қосыңыз:

```powershell
..\.venv\Scripts\Activate.ps1
```

Егер виртуалды орта әлі жасалмаса, алдымен оны құрыңыз:

```powershell
py -m venv ..\.venv
```

Содан кейін іске қосыңыз:

```powershell
..\.venv\Scripts\Activate.ps1
```

Ортаның дұрыс іске қосылғанын тексеріңіз:

```powershell
python --version
python -m pip --version
```

### 5.3. Тәуелділіктерді орнату

Жобаның қажетті Python кітапханаларын `requirements.txt` файлы арқылы орнатыңыз:

```powershell
python -m pip install -r requirements.txt
```

Орнатылған Django нұсқасын тексеріңіз:

```powershell
python -m django --version
```

### 5.4. Қоршаған орта айнымалыларын баптау

Жобаның негізгі бумасында `.env` файлы болуы керек. Бұл файлда Gemini API кілті және қажетті конфигурация сақталады.

Мысалы:

```env
GEMINI_API_KEY=your_gemini_api_key
GEMINI_MODEL=gemini-3.8-flash
```

`your_gemini_api_key` орнына өзіңіздің API кілтіңізді енгізіңіз. Модель атауын жобада қолданылатын нақты модельге сәйкес көрсетіңіз.

**Қауіпсіздік ережесі:** `.env` файлын GitHub репозиторийіне жүктемеңіз. API кілтін бастапқы кодқа тікелей жазбаңыз.

### 5.5. Жоба конфигурациясын тексеру

Django жобасының конфигурациясында қателердің бар-жоғын тексеріңіз:

```powershell
python manage.py check
```

Егер тексеру сәтті өтсе, терминалда мынадай хабарлама шығады:

```text
System check identified no issues (0 silenced).
```

### 5.6. Дерекқор миграцияларын орындау

SQLite дерекқорын дайындау және қажетті кестелерді құру үшін:

```powershell
python manage.py migrate
```

Бұл команда Django жүйесінің және жоба қолданбаларының миграцияларын қолданады.

### 5.7. Серверді іске қосу

Жергілікті әзірлеу серверін іске қосыңыз:

```powershell
python manage.py runserver
```

Терминалда көрсетілген мекенжайды браузерде ашыңыз. Әдетте ол:

```text
http://127.0.0.1:8000/
```

Серверді тоқтату үшін терминалда `Ctrl + C` пернелерін басыңыз.

### 5.8. Негізгі мүмкіндіктерді тексеру

Жоба іске қосылғаннан кейін келесі әрекеттерді тексеріңіз:

1. Басты беттің ашылуы.
2. Қазақ және орыс тілдерін ауыстыру.
3. Өнімдер бойынша рецепт генерациялау.
4. Рецептті сақтау және сақталған рецепттер тізімін ашу.
5. Дайындау режимінде қадамдарды растау және келесі қадамға өту.

Егер қате пайда болса, терминалдағы хабарламаны тексеріп, оның себебін анықтаңыз.
